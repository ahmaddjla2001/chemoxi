CHEMOXI Basic Website
======================

Files:
- index.html — Home
- about.html — About CHEMOXI
- services.html — Services / R&D / Applications
- products.html — Purixa and specialty products
- contact.html — Contact and medical diagnostics control-solution section
- style.css — shared responsive styling
- assets/ — visual assets extracted from the supplied design reference

Deployment:
1. Upload all files and the assets folder to the same directory on your web host.
2. Open index.html through your domain.
3. For Netlify, drag the whole folder (or ZIP contents) into the deploy area, or connect a Git repository.
4. Replace the extracted reference images with your original high-resolution CHEMOXI logo/product photos when available.

Note:
The contact form uses a mailto action for this basic static version. For reliable web-form delivery, connect it later to a form service or a server-side email endpoint.
